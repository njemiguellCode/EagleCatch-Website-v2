# EagleCatch Website v2 - Preview Run Doc

## Overview
This is a pure static HTML website with no build process, dependencies, or dev server required.

## How to View
1. Open `index.html` directly in a browser, or
2. Register with `register_preview` using `htmlPath` pointing to `index.html`

## File Structure
- `index.html` — Landing page
- `about.html` — About page
- `contact.html` — Contact page
- `find.html` — Find items page
- `item.html` — Individual item page
- `assets/` — Static assets (images, CSS, JS)

## No Build Required
No `package.json`, no dependencies, no compilation. Just HTML/CSS/JS files served directly.
